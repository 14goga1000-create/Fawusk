# Образцы для проверки CustomAV / FawReader

ordinary.faw — обычный FAW 3 с безопасными тестовыми документами и короткими медиа. Ожидается завершённая проверка без положительных признаков. Это не гарантия отсутствия всех возможных угроз.

damaged-checksum.faw — копия с намеренно изменённым последним байтом контрольной суммы каталога. Ожидается INCOMPLETE SCAN / MANUAL REVIEW, scan_complete=false; распаковка/просмотр заблокированы.

В пакете нет живых вирусов и EICAR-файла. EICAR внутри всех вариантов FAW и вложенного FAW проверяется тестами исходников; он создаётся во время теста и является безвредным тестовым маркером.

JSON-отчёты рядом созданы тем же CustomAV, который используется в Fawusk. Для самостоятельной проверки:

```
Fawusk-alpha-0.7.exe --scan-customav ordinary.faw --report new-ordinary-report.json
Fawusk-alpha-0.7.exe --scan-customav damaged-checksum.faw --report new-damaged-report.json
```

Запускайте EXE как процесс с аргументами без shell, дождитесь завершения и прочитайте отчёт. Код 0 — завершённая clear/review проверка (смотрите verdict), 2 — malware/test, 3 — неполная проверка/ошибка. Существующие JSON не перезаписываются.
