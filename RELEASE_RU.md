### Fawusk Alpha 0.4 — быстрый доступ и безопасный просмотр

Fawusk — локальный архиватор для Windows, который мы развиваем как конкурента WinRAR и 7-Zip. В этой альфе обновлены FAW 3, просмотр файлов и настройки сжатия. Превосходство над другими архиваторами пока не заявляем.

### ⚡ Обновлённый FAW 3
- Индексированный каталог: содержимое нового архива открывается без распаковки всего потока.
- Solid-группы по 8 МиБ и два параллельных задания сжатия.
- Несжимаемые группы хранятся без дополнительного сжатия.
- SHA-256 для групп и файлов; данные проверяются при извлечении.

### 🔒 Просмотр выбранного файла
- Двойной клик по фото, видео, аудио или документу извлекает **только выбранный файл** в Temp и открывает его приложением Windows.
- Новый FAW 3 декодирует только нужные группы. Старые архивы могут требовать чтения всего потока, но остальные файлы на диск не записываются.
- Приложения, скрипты, ярлыки, макросодержащие документы и маскировка расширений запрещены для запуска из архива.
- Для таких файлов сначала нужна полная обычная распаковка и самостоятельная проверка. Просмотрщик — **не антивирус и не песочница**.

### 🎚️ Простые настройки
- Сжатие: **Быстрый / Хороший / Максимальный**.
- Форматы: **FAW 3 / FAW 2 / FAW 1 / ZIP**.
- Один открытый путь или архив на окно. Настройки доступны прямо в окне, без перегруженного меню.

### ✅ Проверка данных
В тестах проверены случайные двоичные данные, кириллица, пустые файлы/папки, длинные пути, старые версии FAW, выбранное извлечение, повреждённые архивы и отмена. Для тестового файла размером **5 ГиБ** SHA-256 исходника и распакованного результата совпал.

### ⚠️ Перед установкой
- **Новый FAW 3 требует alpha 0.4 или новее.** Alpha 0.3 его не прочитает; для обмена выбирайте FAW 1/2 или ZIP. Старые FAW 3 читаются.
- Цель **5 ГБ за 5–6 секунд пока не достигнута**. В инженерном тесте синтетических нулевых данных в Linux с 2 vCPU упаковка заняла около 11,23 с; параллельно шли другие сборочные/тестовые задачи. Это не показатель скорости на обычных файлах или Windows.
- Быстрое чтение проверяет каталог, а не все данные. Полная распаковка проверяет все файлы.
- Просмотр ограничен 1 ГиБ на файл; нужны установленные приложения Windows. Temp очищается по возможности при следующем просмотре или закрытии окна, заблокированные файлы могут остаться.
- RAR, 7z, шифрование и цифровая подпись EXE пока отсутствуют. Проверки Windows выполнены через Wine; тестирование на настоящей Windows 10/11 ещё необходимо.

### 📦 Запуск
**Windows 10/11 x64.** Скачайте `Fawusk-alpha-0.4.exe` и запустите. Без установки, .NET/Mono и прав администратора. Сверяйте SHA-256. Это альфа — тестируйте на копиях важных файлов.
