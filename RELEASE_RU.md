### Fawusk Alpha 0.3
Один путь на окно, просмотр папок и новый FAW 3 Solid Stream.

<br />

### Навигация
- Открытый файл или папка заменяет предыдущий путь в окне.
- Папка показывает содержимое; двойной клик входит в подпапку, «Вверх» возвращает к родителю.
- Обычный файл открывается внешним приложением Windows. Для отдельно открытого файла показывается только путь; двойной клик по нему запускает назначенное приложение.
- FAW 1/2/3 и ZIP распознаются и показывают проверенное содержимое. Файл внутри архива сначала нужно распаковать.
- Несколько путей можно открыть в отдельных окнах.

<br />

### Пути и интеграция
- Современные диалоги Windows для открытия и сохранения.
- Исправлена нормализация длинных абсолютных путей в собственных вызовах Windows.
- Проверены сохранение и распаковка в дальних каталогах с длинными путями и кириллицей.
- В меню «…» можно добавить Fawusk в «Открыть с помощью» для .faw. Приложение по умолчанию принудительно не меняется.

<br />

### FAW 3 Solid Stream
- Общая история Zstandard до 8 МиБ между файлами.
- Компактные сжатые записи и CRC-32 каждого файла.
- SHA-256 контейнера за один проход.
- Чтение старых FAW 1/2 сохранено.

Похожие файлы могут сжиматься лучше благодаря общей истории. Уменьшение любых данных не гарантируется; solid требует памяти и последовательного чтения. Просмотр большого архива сейчас выполняет полный проход с проверкой, без мгновенного произвольного доступа.

FAW — собственный контейнер на основе существующего Zstandard, не новый алгоритм сжатия. SHA-256 не обеспечивает шифрование или подтверждение авторства.

<br />

### Совместимость и запуск
Windows 10/11 x64, `Fawusk-alpha-0.3.exe`, без установки и прав администратора.

Alpha 0.1/0.2 не читают FAW 3: получателю нужна Alpha 0.3, либо используйте ZIP. RAR/7z, пароли и шифрование пока не реализованы.

<br />

### Статус проекта
**Fawusk разрабатывается как конкурент WinRAR и 7-Zip.** Это цель проекта, а не доказанное превосходство текущей альфы.

Используйте копии файлов и проверяйте результат. Сборка не подписана: не отключайте защиту для недоверенного файла. Проверки выполнены на Linux и через Wine; полноценное тестирование на настоящей Windows ещё необходимо. Ограничения и результаты — в `docs/TESTING.md`.
