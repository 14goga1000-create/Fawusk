### Fawusk Alpha 0.5 — иконки, очистка Temp и оптимизация потоков

Fawusk — локальный архиватор для Windows, который мы развиваем как конкурента WinRAR и 7-Zip. В этом обновлении улучшены понятность интерфейса, работа с временными файлами и ограниченный многопоточный конвейер. Превосходство над конкурентами пока не заявляем.

### Интерфейс
- FAW 2 переименован из «Блочный» в **«Классический»**.
- Добавлены графические иконки папок, архивов и категорий файлов — без эмоджи.
- Строки списка стали просторнее; двойной клик и клавиатурная навигация сохранены.
- Один открытый путь или архив на окно.

### Оптимизация под четыре ядра
- До трёх рабочих потоков кодека с резервом ресурса для чтения, записи и проверки данных.
- Автоматическое уменьшение числа работников для небольших архивов и меньшего CPU-бюджета.
- Повторное использование буферов вместо новых выделений для каждой группы.
- Параллельное предварительное чтение, проверка и декодирование групп при распаковке.
- Очереди ограничены: весь архив в RAM не загружается.

### Очистка временных файлов
- При обычном закрытии удаляются временные файлы просмотра Fawusk.
- Если внешний просмотрщик заблокировал файл, отдельный помощник повторяет удаление до двух минут после завершения программы.
- Оставшиеся помеченные папки подбираются при следующем запуске.
- Чужие данные в Temp и файлы активных окон не удаляются.

Мгновенное удаление при любых обстоятельствах не гарантируется: блокировки Windows, аварийное завершение и права доступа могут мешать очистке. Просмотрщики не завершаются принудительно. Старые непомеченные папки из предыдущих версий удаляйте вручную после закрытия просмотрщиков.

### Совместимость и проверка
- FAW 3 не меняет формат: совместимость с alpha 0.4 сохранена.
- Поддержка FAW 1/2/3 и ZIP; RAR, 7z и шифрование пока отсутствуют.
- Сохранены проверки SHA-256 и запрет запуска приложений/скриптов из архива. Это не антивирус и не песочница.
- В инженерном тесте 5 ГиБ нулевых данных упакованы за **6,919 с** на 2 vCPU в Linux; SHA-256 после распаковки совпал. Это не результат для реальных данных, Windows или физического четырёхъядерного ПК. Универсальная цель 5–6 секунд пока не достигнута.

### Запуск
**Windows 10/11 x64.** Скачайте `Fawusk-alpha-0.5.exe` и запустите. Без установки, .NET/Mono и прав администратора. EXE не подписан — сверяйте SHA-256. Windows-сборка проверена через Wine; настоящая Windows ещё требует тестирования. Это альфа — используйте копии важных файлов.
