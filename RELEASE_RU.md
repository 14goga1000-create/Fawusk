# Alpha 0.1

**Fawusk alpha 0.1 — первая тестовая версия портативного архиватора для Windows.**

Простой нативный интерфейс, упаковка и распаковка файлов и папок в **ZIP** и **FAW**, без установки и сетевых функций.

## Что доступно

- Форматы ZIP и собственный экспериментальный контейнер `.faw`.
- Три уровня сжатия: быстрое, сбалансированное и максимальное.
- Перетаскивание файлов, вложенные и пустые папки, русские имена.
- Работа в фоне, индикатор прогресса и отмена операции.
- Проверка целостности: CRC для ZIP и дополнительная SHA-256 для FAW.
- Распаковка в новую папку без перезаписи существующих данных и с проверкой опасных путей.

## Запуск

Скачайте **Fawusk-alpha-0.1.exe** и запустите на **Windows 10 / 11 x64**. Устанавливать Go не нужно. Для проверки загрузки используйте приложенный SHA-256.

## Важно

Это **альфа для тестирования**: используйте копии файлов и проверяйте результат распаковки. EXE пока не подписан; Windows может предупредить о неизвестном издателе. Не отключайте защиту для запуска недоверенной сборки.

**RAR и 7z, пароли и шифрование пока не поддерживаются.** FAW — собственный контейнер на основе ZIP/DEFLATE, а не новый алгоритм сжатия. SHA-256 не подтверждает авторство архива. Превосходство над WinRAR / 7-Zip по скорости, ресурсоёмкости и безопасности пока не заявляется.

Лимиты alpha 0.1: **100 000 элементов, 8 ГиБ на файл и 20 ГиБ распакованных данных**. Ссылки, junction и специальные файлы не предназначены для упаковки. Это не антивирус: не запускайте недоверенные извлечённые файлы.

Проверки выполнены на Linux и через Wine; полноценная проверка на реальной Windows ещё нужна. Подробности и ограничения тестов — в `docs/TESTING.md`.

Нашли ошибку? Создайте Issue с версией Windows, описанием действия и текстом ошибки. Не прикладывайте личные данные.
