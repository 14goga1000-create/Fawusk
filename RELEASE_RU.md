### Fawusk Alpha 0.6 — табличный проводник и расширенный ZIP

Fawusk — локальный архиватор для Windows, который мы развиваем как конкурента WinRAR и 7-Zip. В этой альфе обновлены проводник, метаданные и совместимость ZIP. Превосходство над другими архиваторами пока не заявляем.

### Таблица вместо списка
- Колонки **Имя / Размер / Дата изменения** для обычных папок и архивов.
- Размеры в КБ/МБ/ГБ, даты в локальном времени компьютера.
- Сортировка по клику на заголовок; папки остаются первыми.
- Графические иконки и правило «один открытый путь на окно» сохранены.
- FAW 3 читает метаданные из компактного каталога без смены формата.

### Расширенная поддержка ZIP
- Открытие по каталогу без предварительного декодирования всех файлов.
- Распаковка Store, Deflate, BZip2 и Zstandard; ZIP64, комментарии и дескрипторы данных.
- UTF-8, стандартные CP437-имена, Unicode Path и безопасные относительные Windows-пути.
- Выбранный просмотр ZIP извлекает только нужный файл.
- CRC проверяется при извлечении. Повреждённые файлы не публикуются как успешно распакованный результат.

### Пустые элементы без ошибок
- Пустой файл отображается как «0 КБ».
- Папки не добавляются к сумме файловых данных и считаются отдельно.
- Пустые папки и архивы сохраняются; таблица остаётся корректной.
- Записи о папках всё же занимают немного места в архиве — нулевой служебный объём не обещаем.

### Меньше лишней работы
- Виртуальная таблица вместо отдельных native-элементов для каждого файла.
- Фоновое, отменяемое чтение размеров и дат папки.
- Быстрое чтение каталога ZIP без полной распаковки для просмотра списка.
- Сохранены ограниченный конвейер FAW 3, повторное использование буферов, проверки данных и очистка своих Temp-файлов.

### Важно
Колонка размера в архиве показывает **исходный размер**, не отдельный сжатый вес solid-файла. Отсутствующие данные показаны как «—».

ZIP с паролем/AES, многотомные ZIP, Deflate64 и ZIP-LZMA пока не поддерживаются. RAR, 7z и шифрование отсутствуют. Быстрое чтение каталога не проверяет все данные; просмотрщик не является антивирусом или песочницей.

FAW 3 остаётся совместимым с alpha 0.4/0.5. Windows EXE проверен через Wine; тестирование на настоящей Windows и физическом четырёхъядерном ПК ещё необходимо. Новой гарантии скорости или меньшего RAM на всех данных нет.

### Запуск
**Windows 10/11 x64.** Скачайте `Fawusk-alpha-0.6.exe` и запустите. Без установки, .NET/Mono и прав администратора. EXE не подписан — сверяйте SHA-256. Это альфа: тестируйте на копиях важных файлов.
