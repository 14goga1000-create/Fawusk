### Fawusk Alpha 0.7 — CustomAV и новые иконки

Fawusk — локальный архиватор для Windows, который мы развиваем как конкурента WinRAR и 7-Zip. В этой версии добавлены встроенная статическая проверка CustomAV и понятные иконки типов файлов.

### Проверка при открытии архива
- CustomAV получает содержимое файлов, а не только сжатую оболочку архива.
- Модуль FawReader читает FAW 1, FAW 2, старый и индексированный FAW 3 с проверками размеров, путей и CRC/SHA.
- Поддержаны ZIP и ограниченная рекурсивная проверка вложенных FAW, ZIP и JAR.
- Сверху показан результат: зелёный — угрозы не обнаружены, красный — есть подозрительные файлы, жёлтый — ручная проверка, серый — проверка неполная.
- EICAR отмечается отдельно как тестовая сигнатура, а не настоящий вирус.

### Безопасность операций
- Блокирующие находки запрещают просмотр и распаковку.
- Новый архив проверяется до публикации готового файла.
- При распаковке потоки повторно проверяются до публикации результата.
- Повреждение, пароль, неподдерживаемый контейнер, лимит или проверка одного entry не дают зелёный статус всего архива.
- Файлы из архива не исполняются сканером; подозрительные оригиналы не удаляются и никуда не отправляются.

### Отчёт CustomAV
- Кнопка «Отчёт…» рядом с результатом проверки.
- Полный JSON через меню «…»: entry, формат контейнера, SHA-256, размер, полнота проверки, rule и причина.
- Отдельные malware / test / review scores.
- Самостоятельный режим `--scan-customav` для интеграции и тестирования без окна приложения.

### Иконки и интерфейс
- Отдельные графические иконки видео, аудио, фото, PDF, таблиц, презентаций, кода и приложений.
- Видео теперь отображается значком кадра с кнопкой воспроизведения, а не текстовым документом.
- Таблица «Имя / Размер / Дата изменения», сортировка и один путь на окно сохранены. Эмоджи не используются.

### Важно перед установкой
CustomAV — адаптированный Go-порт статических правил 0.5, а не полноценная замена Defender и не гарантия отсутствия вирусов. Встроенная база содержит EICAR; реальные угрозы ищутся эвристиками или добавленными сигнатурами. Возможны ложные срабатывания. Отличия от Python reference описаны в исходниках.

**В этой альфе анализ одного файла ограничен 16 МиБ.** Более крупные файлы хешируются полностью, но делают проверку неполной; строгая политика блокирует просмотр/распаковку/публикацию. Вложенные данные ограничены 1 ГиБ, глубина — 3, число проверяемых файлов — 10 000. Это может затронуть обычные большие видео и игровые архивы.

Полная проверка требует декодирования данных и добавляет время открытия. Прежние показатели скорости без этого режима к нему не относятся.

### Запуск
Windows 10/11 x64. Без установки, Python, .NET/Mono и администратора. EXE не подписан — сверяйте SHA-256. Сборка проверяется через Wine; настоящая Windows и независимая проверка безопасности ещё необходимы. Тестируйте на копиях важных файлов.
