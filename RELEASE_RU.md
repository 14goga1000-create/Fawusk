# Alpha 0.2

**Fawusk alpha 0.2 — более простой интерфейс и новый движок FAW.**

## Интерфейс

- Компактный главный экран: добавление, список, выбор FAW/ZIP, упаковка и распаковка.
- Настройки сжатия, очистка списка и открытие результата — в меню «…».
- Место сохранения выбирается при упаковке; постоянное поле пути убрано.
- Во время работы распаковка заменяется кнопкой отмены.

## FAW 2

- Блочное сжатие Zstandard по 1 МиБ.
- Автоматическая запись блока без сжатия, если он не уменьшается.
- Переиспользуемые буферы и один рабочий поток кодека.
- CRC-32 блоков и итоговая SHA-256, вычисляемая за один проход.
- Сохранено чтение старого FAW 1 из alpha 0.1.

**Важно:** alpha 0.1 не читает новые FAW 2. Получателю нужна alpha 0.2 либо используйте ZIP. FAW — собственный контейнер, а не собственный новый алгоритм сжатия. Мы готовим конкурентный продукт, но пока не заявляем превосходство над WinRAR и 7-Zip.

## Запуск и ограничения

Windows 10/11 x64, `Fawusk-alpha-0.2.exe`, без установки и прав администратора. Сборка не подписана: не отключайте защиту для запуска недоверенного файла.

RAR/7z, пароли, шифрование, solid-сжатие, дедупликация и просмотр архива пока не реализованы. До 100 000 элементов, 8 ГиБ на файл и 20 ГиБ распакованных данных. Ссылки/junction и специальные файлы не поддерживаются.

Это альфа: используйте копии и проверяйте результат. Тесты выполнены на Linux и через Wine; полноценная проверка на настоящей Windows ещё нужна. Подробности в `docs/TESTING.md`.
